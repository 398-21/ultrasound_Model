What	Where to get it
combined dataset	The dataset attached as combined to your Kaggle notebook. Open it from the notebook's Input panel and download it. data/combined/train also works if the zip has only one combined level.
emotion-detection-fer	The other dataset attached to the notebook. Only its test/ folder is used.
baseline_run/checkpoints/	Optional. From the output of the Kaggle version that printed your 0.72 report, download the checkpoints/ folder. With it, the baseline arm only evaluates (about 30 min) instead of retraining (2.5–5.5 h). It needs latest.json plus the ckpt_phase2_epochNN files named inside it; copying the whole folder is simplest.
You don't add anything else. The notebook writes extract_landmarks.py next to itself, and the first geometry run downloads MediaPipe and its model. Leave about 15 GB free.

What changed in exp-tuning.ipynb:

Desktop folder block: the settings cell now has a block with PROJECT_ROOT, DESKTOP_DATA, DESKTOP_OUTPUTS and DESKTOP_SCRATCH. The defaults are the folder the notebook is in, its data/ and outputs/, and ~/fer_scratch. Edit them only if your layout differs; on Kaggle they're ignored.
Layout check: before anything heavy runs, it prints the folders it found and each set's classes and file counts. If a dataset folder is missing, it stops with a message naming the folder it expected.
Run notes: the "How to run" cell now shows the folder tree above.
Put the project inside WSL, not on the Windows drive: in WSL2, the Windows drive under /mnt/c is slow for tens of thousands of small files, and every run rebuilds about 150k images. That's why scratch defaults to ~/fer_scratch, and why the whole project is best kept in your WSL home folder.

Download vgg16_cbam_vit_incremental_unfreeze_improved.index and .data-00000-of-00001 from that run's output.

Set PRETRAINED_WEIGHTS = os.path.join("data", "baseline_run", "vgg16_cbam_vit_incremental_unfreeze_improved").
I tested this: weights saved the way your Kaggle notebook saved them load with all 113 tensors identical.
